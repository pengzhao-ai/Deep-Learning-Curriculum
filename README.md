# Deep Learning Learning Journey 🚀

A hands-on repository for learning deep learning fundamentals with PyTorch.

## Learning Roadmap

1. **Gradient Descent & Backpropagation** — Understand how neural networks learn
2. **Building Blocks** — Layers, activations, loss functions, optimizers
3. **CNN (Convolutional Neural Networks)** — Image understanding with convolutions
4. **ViT (Vision Transformer)** — Attention-based image understanding
5. **CNN vs ViT** — Compare architectures, trade-offs, and use cases

## Setup

```bash
# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```
